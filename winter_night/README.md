# ❄️ Winter Night — ASCII-анимация в терминале

Зимний лес ночью: падает снег, костёр горит и искрит, ёлки качаются на ветру,
светлячки мигают, огонь подсвечивает всё вокруг тёплым светом.

## Запуск

```bash
python3 winter_night/winter_night.py
```

Нужен только Python 3 (на Windows: `pip install windows-curses`).
Лучше запускать в терминале на весь экран и с поддержкой 256 цветов
(iTerm2, Terminal.app, Windows Terminal, любой Linux-терминал).

## Управление

| Клавиша | Что делает |
|---|---|
| `q` / `Esc` | выход |
| `пробел` | пауза |
| `+` / `-` | скорость |
| `←` / `→` (`a` / `d`) | ветер |
| `↑` / `↓` (`w` / `s`) | снег |
| `[` / `]` | огонь |
| `,` / `.` | светлячки меньше / больше |
| `g` `m` `p` | свечение / луна / искры |
| `h` | помощь |

Флаги: `--fps 30`, `--seed 42` (другая расстановка ёлок), `--preview` (одна картинка).
